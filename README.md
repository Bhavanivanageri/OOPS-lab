# Object-Oriented Programming (OOPS) Lab

## 🎯 Overview

Object-Oriented Programming (OOP) is a programming paradigm that organizes code using classes and objects. It helps develop modular, reusable, and maintainable programs.

This repository contains practical implementations of fundamental and advanced C++ concepts, including classes, objects, constructors, destructors, inheritance, polymorphism, operator overloading, exception handling, and file handling.

Each program is maintained in a separate source file for easy understanding and execution.

## 🎓 Objectives

- Understand the fundamentals of C++ programming.
- Learn how to create and use classes and objects.
- Implement constructors and destructors.
- Understand inheritance and polymorphism.
- Practice function and operator overloading.
- Learn encapsulation and abstraction.
- Work with pointers and dynamic memory allocation.
- Implement exception handling and file operations.
- Develop logical thinking through practical programming exercises.

## 🧠 OOP Concepts

### 1. Classes and Objects

Classes define data and behavior, while objects are instances of classes.

### 2. Encapsulation

Encapsulation combines data and functions within a class and controls access to its members.

### 3. Abstraction

Abstraction exposes essential functionality while hiding unnecessary implementation details.

### 4. Inheritance

Inheritance allows a derived class to reuse and extend the functionality of a base class.

### 5. Polymorphism

Polymorphism allows the same interface to represent different forms of behavior, including compile-time and runtime polymorphism.

### 6. Constructors and Destructors

Constructors initialize objects, while destructors perform cleanup when objects are destroyed.
